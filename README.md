# Admin Dashboard

A responsive admin dashboard built with pure HTML and CSS Grid, recreating a real-world layout with a sidebar, header, and a main content area split into projects, announcements, and trending sections.

This project was built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard) curriculum, focused on practicing CSS Grid for complex, nested layouts.

## 🛠️ Built With

- **HTML5** — semantic structure
- **CSS3** — Grid & Flexbox for layout
- **Google Fonts** — Roboto
- **[Material Design Icons](https://pictogrammers.com/library/mdi/)** — SVG icons for navigation and actions

No frameworks, no build tools — just vanilla HTML and CSS.

## ✨ Features

- Fixed sidebar navigation with icon + label items
- Two-row header: search bar & user info, plus a greeting section with action buttons
- Main content area organized with nested CSS Grid:
  - **Your Projects** — card grid with title, description, and quick-action icons
  - **Announcements** — stacked list with dividers
  - **Trending** — user list with avatars and project names
- Fully built using CSS Grid and Flexbox, with grids nested inside grids for each section

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/admin-dashboard.git
   ```
2. Navigate into the project folder
   ```bash
   cd admin-dashboard
   ```
3. Open `index.html` in your browser (or use a live server extension in your code editor)

No installation or dependencies required.
